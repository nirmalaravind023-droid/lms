# Roadmap

This roadmap reflects code and planning documents currently in the repository. It is not a release commitment.

## Near term

- Resolve the seven documented failing tests.
- Add reproducible sample-data tooling beyond the existing test-admin command.
- Harden production deployment settings, media handling, and service exposure.
- Decide whether to integrate, archive, or remove the Vite frontend prototype.

## Future exploration

- Improve analytics by connecting the Streamlit dashboard to LMS data.
- Continue calendar, assessment, certificate, and learning-content improvements described in [architecture.md](architecture.md).
- Reassess the archived NestJS and legacy frontend projects before any public release.

## Known limitations

- The default environment is development-oriented.
- The Streamlit dashboard uses sample data.
- The Vite frontend is not served by Django.
- No project license has yet been selected.

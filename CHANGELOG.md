## Release process

1. Update this file with user-facing changes.
2. Ensure checks, tests, linting, and the calendar build have been run.
3. Update the version in `package.json` when releasing the Node build package.
4. Tag the release as `vMAJOR.MINOR.PATCH` and publish release notes.
